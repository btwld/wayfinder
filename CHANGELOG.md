# Changelog

Release history of the `okf_profile` Dart package (the `okfp` toolchain).
This is package semver; profile releases are recorded in `profile/`, not here.

## 0.2.0

- Add the manifest, bundle declaration, profile rule registration, and dispatch
  contracts.
- Consume the OKF 0.2 contract surface for findings, suppressions, catalogs,
  reports, and verdicts.

## 0.1.0

- Bootstrap the `okf_profile` package and the `okfp` command-line interface.
- Declare the `validate` command surface (`--output`, `--profile`, `--strict`);
  behaviour lands with the Verdict wiring.
