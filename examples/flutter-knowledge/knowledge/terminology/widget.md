# Definition

A widget is an immutable description of part of a user interface. Widgets
compose into a hierarchy describing the UI for the current configuration and
state; the framework rebuilds the necessary parts when state changes.[^flutter-glossary]

See [Flutter framework layers](/architecture/flutter-framework-layers.md) for
how widgets relate to elements and render objects.
