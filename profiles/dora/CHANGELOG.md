# Dora Profile changelog

## 1.0

Initial Dora-specific guidance package, extending Bitwild without adding
machine rules or vocabulary. It documents source-first retrieval, evidence
handling, lifecycle ambiguity, session continuity, and data minimization while
referencing the original Dora policies in place. Existing Bitwild-conformant
bundles need no migration; adopting this Profile changes only the installed
review guidance and retains all inherited Bitwild findings.
