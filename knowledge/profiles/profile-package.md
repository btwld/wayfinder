# Definition

A directory at one Git revision holding `wayfinder-profile.json` in the
[package format](../../implementation/okf-implementation-guide.md#54-identity-release-and-format), and optionally a README, a changelog, and a skill. The package is the
Profile; its prose explains it and adds no requirement.

# Avoid

Manifest, rule catalog
